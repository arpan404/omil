# Omil

Omil is a planned local-first dictation app for iPhone, iPad, and Mac. The goal is to transcribe speech on device, remove filler and repetition, resolve spoken self-corrections, and keep cleanup inspectable and reversible.

The first milestone tests correction quality on recorded speech, reliable Mac insertion, and an iPhone app-and-keyboard workflow with local inference. Model choices, device support, and release order depend on those results. Implementation and device testing have not started.

Start with the [product and build plan](docs/product-plan.md). The cited model and platform research lives in [the on-device speech survey](docs/research/on-device-speech-stack.md).
